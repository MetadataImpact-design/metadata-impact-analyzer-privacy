Privacy Policy — Metadata Impact Analyzer

Last updated: September 27, 2026

Metadata Impact Analyzer is a Chrome extension for Salesforce developers, architects, consultants, and release managers. It is designed to minimize data collection and does not operate a developer-hosted application server or database for core analysis.

Summary: Core dependency extraction, risk scoring, graph generation, and regression-test recommendations run locally in the browser. Optional AI explanation is disabled by default. Licensing is validated directly with Lemon Squeezy.

1. Local analysis

Core dependency extraction, risk scoring, graph generation, and regression-test recommendations run in the user's browser using metadata or code the user provides, or structured content the user deliberately asks the extension to extract from a recognized Salesforce page.

2. Salesforce content

The extension does not intentionally scrape arbitrary Salesforce page text. Active-tab extraction is conservative and targets recognized structured code or metadata content. Users may also paste Apex, Flow XML, JSON, XML, or other supported metadata directly into the extension.

3. Optional OpenAI processing

AI explanation is optional and disabled by default. When a user enables AI explanation, locally derived dependency evidence is sent directly from the user's browser to OpenAI using the user's own OpenAI API key. Raw source code or metadata is excluded by default and is sent only when the user separately enables the raw-source option. OpenAI's terms and privacy practices apply to that direct API use.

4. OpenAI API keys

The OpenAI API key is held in Chrome session storage by default. A user may explicitly choose to remember the key on the device, in which case it is stored in Chrome local storage. Metadata Impact Analyzer does not operate a server that receives or stores the user's OpenAI API key.

5. Licensing and payments

Paid purchases and checkout are handled by Lemon Squeezy. License activation and validation are performed directly against Lemon Squeezy's licensing service. License identifiers, entitlement information, validation timestamps, and related activation state may be stored locally in Chrome storage so the extension can remember Pro access and support a limited offline grace period after a successful validation. Lemon Squeezy's own terms and privacy practices apply to checkout, payment, and licensing services.

6. Local storage and retention

The extension may store workspace state, settings, monthly free-usage counters, license state, and user preferences locally in Chrome storage so the side-panel experience can persist across tab switches and browser sessions. Users can remove the extension or clear its extension storage through Chrome to remove locally stored application state.

7. Analytics and advertising

The current product does not include third-party advertising trackers and does not operate a developer-hosted behavioral analytics backend.

8. Data selling

Metadata Impact Analyzer does not sell user data.

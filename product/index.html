Built for safer Salesforce changes

Metadata Impact Analyzer turns a proposed code or metadata change into a compact pre-deployment risk review. The deterministic engine extracts observable evidence first; optional AI is layered on top for explanation and additional test guidance.

◎

Dependency evidence

Detects object/field references, SOQL, DML, Apex collaborators, Flow XML references, callouts, async execution, and other change signals from supplied metadata.

⚠

Risk & confidence

Produces an evidence-based High, Medium, Low, or Unknown risk result plus confidence and clear scope language. Unknown is never silently treated as Low.

✓

Regression-test plan

Recommends focused tests for writes, automation, integrations, asynchronous behavior, security enforcement, formulas, and referenced components.

Architecture & data handling

Backend-free product architecture

The extension does not operate a developer-hosted application server or database. Core dependency evidence and risk scoring run in the browser.

Optional BYOK AI

AI explanation is optional and off by default. When enabled, dependency evidence is sent directly from the browser to OpenAI using the user's own API key. Sending raw source is a separate opt-in setting.

Risk analysis is based on the metadata/code supplied or deliberately extracted from supported structured views. It is not a whole-org dependency audit, and its findings do not guarantee a deployment is safe.
